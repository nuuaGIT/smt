# Local game-derived data

`world_resource_nodes.json` is a local copy of the resource-node table from
the Satisfactory Logistics project.

Source: https://github.com/rockfactory/satisfactory-logistics

The source project is distributed under the MIT License. Its copyright and
license notice are preserved in the source repository.

`map_highres.png` is game-derived Satisfactory map artwork used locally as a
visual background. Satisfactory and its assets belong to Coffee Stain Studios.

`src/save_parser_core/` contains the focused parser core derived from the
`satisfactorymap` project by Valentin P. It is distributed under the GNU Affero
General Public License v3; the corresponding source license is preserved in
`src/save_parser_core/SOURCE_LICENSE.txt`.
